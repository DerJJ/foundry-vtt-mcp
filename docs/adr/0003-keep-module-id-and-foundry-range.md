# Keep the module id and the declared Foundry range during the restructure

Status: accepted (2026-11-07)

The module id stays `foundry-mcp-bridge`, because a restructure changes no behaviour and a rename would cost existing worlds their settings. The declared Foundry compatibility range stays as v0.8.6 has it. Whether to narrow it is decided separately, once a live check shows what works on the newest Foundry version.
