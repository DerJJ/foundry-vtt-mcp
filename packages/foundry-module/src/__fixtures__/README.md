# Fixtures

Tests that use fixtures check behaviour against documents shaped like the ones Foundry produces,
instead of against shapes written inside each test.

## Two kinds

- **Synthetic (committed).** `pf2e-synthetic.json` and `dnd5e-synthetic.json` are generated by
  [`scripts/make-synthetic-fixtures.mjs`](../../../../scripts/make-synthetic-fixtures.mjs). Every
  name, description and number in them is invented. Change the generator, run it, commit both.
- **Captured (never committed).** A capture from your own world goes in `__fixtures__/local/`,
  which git ignores. The loader prefers it over the synthetic file, so the same tests then run
  against your real data.

**Never commit a capture.** Worlds contain campaign content and player data, and published
adventure text and compendium entries are copyrighted. A test (`fixtures.test.ts`) fails if a
committed fixture is not marked `"synthetic": true`.

## Capture a world (optional, for yourself)

1. In the world, as the GM, create a **Script** macro with the contents of
   [`scripts/export-fixtures.macro.js`](../../../../scripts/export-fixtures.macro.js) and run it.
2. Move the downloaded `fixtures-<system>-<version>.json` to `__fixtures__/local/`, renamed to
   `<system>-<version>.json`, for example `local/pf2e-8.7.0.json`.

## Use

```ts
import { loadFixtures } from '../test-support/load-fixtures.js';

const fixtures = loadFixtures('pf2e');
describe.skipIf(!fixtures)('against a pf2e world', () => {
  it('...', () => {
    const actor = fixtures!.actors.find(a => a.type === 'character');
  });
});
```
